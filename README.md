# nour0205.github.io

Personal portfolio of Nour Kouider: generative AI and LLM agents.

Live at **https://nour0205.github.io**

- Plain HTML, CSS and JavaScript, no build step.
- FR / EN toggle; light and dark follow the system setting.
- Interactive demos: a step-by-step BPMN agent with human approval, the Recall prompt comparison, a live Mermaid `inheritDir` toggle and an EchoBloom emotion timeline.
- Diagrams are rendered by [Mermaid.js](https://github.com/mermaid-js/mermaid) 11.12.0 (vendored in `assets/vendor/`).

Run locally: `python3 -m http.server` then open http://localhost:8000.
