# nour0205.github.io

Personal portfolio of Nour Kouider, told as a story: from shipping software to building AI agents people can trust.

Live at **https://nour0205.github.io**

- Plain HTML, CSS and JavaScript, no build step.
- FR / EN toggle, light and dark themes.
- Interactive demos: Mermaid `inheritDir` toggle, a step-by-step BPMN agent with human approval, the Recall prompt comparison, and an EchoBloom emotion timeline.
- Diagrams are rendered by [Mermaid.js](https://github.com/mermaid-js/mermaid) 11.12.0 (vendored in `assets/vendor/`).

Run locally: `python3 -m http.server` then open http://localhost:8000.
